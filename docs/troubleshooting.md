# Troubleshooting

## Common issues

### The board does not connect to Wi-Fi

* Verify that the Wi-Fi SSID and password are correctly configured in ESPHome.
* Check that the board is connected to the expected network.
* Try reprogramming the board with a USB cable.

### The servos do not move correctly

* Check the common ground between the ESP32 and the power source.
* Verify that the PWM signal is connected to the correct pin.
* Reduce the mechanical load if the movement is too difficult.
